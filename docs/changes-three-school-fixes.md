- 共享规则升级为 `tracker-events-1.1.0`，浏览器过滤、投影计数和摘要选择使用同一规则。仅元数据变更归 `record_maintenance`（记录维护），保留在完整历史和次级类型中，不占 V6 默认三条预览。

- Cornell 补上轻微、首次违规及校区／学院范围；责任承认完成后“会产生”内部登记、不构成有罪认定；单独说明 Board 或 Dean 认定没有违规时清除案件记录，不能推断责任承认登记也符合清除条件。

- 七语言正文回退提示使用当前界面的语言名称。原默认折叠、90 天、模块位置及红绿增减规则保留。
