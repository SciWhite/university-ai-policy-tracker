## 轻量实现

`UAPT_LOCAL_QA_CHANGE_SUMMARY_PREVIEW` 指向私有预览 manifest；只有 `NODE_ENV=development` 且显式设置时读取，学校范围固定为这三校，最多六个语言叶子。生产环境忽略该变量。缺少 opt-in 时仍是已审核摘要／模板的正常路径，没有可由 URL 参数开启的候选通道。

manifest 只引用原 `.local/changes-p3/pilot/` 下六份草稿及原字节 hash，校验语言、学校、事件、修订对、完整事件／条目／文字／证据指纹。损坏或不匹配不显示候选，未审核状态不冒充已审核。其他学校没有候选数据。

无新公开页面路由，无新历史系统，无服务器上传、构建、进程、磁盘归档或生产指针操作。继续使用一个本地 loopback dev 进程，复用原 P1a 公共导出包，没有复制 137 MB 历史、政策库、图片或依赖。预览新增数据只是一个小 manifest，其他材料为本机截图、日志和审计证据。
