## 本批行为

- `/changes/{slug}` 读取同一 P1a v2 投影，按真实修订逐事件列出。默认全部可查历史，提供自定义 UTC 日期、更新类型、主题／原有分类筛选。默认类型包含更正、补录、结论文字变化、历史原因未分类和暂缓；来源检查及纯页面更新另选，不把其日期推断成学校政策生效日期。
- 匹配总数先于每页 6 条分页计算；筛选改变时回到第一页。缺日期事件在全部历史中保留，自定义日期不凭空填日期。非法、早于记录起点、部分覆盖和无匹配分别表达。正文原地展开，当前筛选不写入 URL，刷新回到全部历史。
- `/changes/{revision}/{slug}` 保持既有 URL，实际存在于该校事件投影的修订采用冻结事件内容。新旧文字、补录、暂缓及证据链接与 V6 模块复用 `ChangeEventContent`，不从当前学校 Claims 重建旧修订，不生成学校原文 diff 或 AI 摘要。
- 同 Claim ID 精确配对且真实文字不同才出现红减绿加；近似匹配和缺旧文不画直接比较。来源检查独立分类，没有同范围新旧官方原文时不显示原文增减。无 Claim 计数的元数据修订采用类别标签，避免显示“修订 0 条”。
- 主站与 zone 复用同一页面实现；zone 的各语言路由转发至同一入口，避免中文路径继续叠加旧说明或绕过修订页。alias 重定向先于读取。七语界面文案本地化，政策文字保留原文及 `lang`；canonical 指回对应语言和原有路径，未增加 noindex、页面 URL 或 sitemap/通知集。
- 未选 v2 时保留原消费者；v2 损坏或 V6 fingerprint 不匹配时拒绝读取，不用旧聚合数据伪装成功。旧全局发布、未形成该校事件的历史 artifact URL 仍由原路由承接；它们不再混入该校事件列表。原页面更新 fragment 保留页首兼容锚点，不把旧的共享页面说明重新归因为后来加入的学校事件。原组件及发布原件未删除。
