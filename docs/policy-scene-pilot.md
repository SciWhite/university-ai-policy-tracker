# Two-university policy scene pilot

This is a narrow exception to the shared student-first detail-page rule against
university-specific hero art. It applies only to `harvard-university` and
`manchester` within the existing ten-page index-recovery cohort. Both pages use
the same hero component and recurring guide character. No other university
page receives a scene as part of this release.

The artwork introduces a student situation; it does not convey permission,
prohibition, or an official university statement. The visible guidance is
grounded in the existing reviewed claims. The hero renders only while the
pinned reviewed-claims basis still matches and the expected student snapshot
state holds: effective strong for Harvard, and no strong snapshot with the
existing curated claims summary for Manchester. Manchester keeps its explicit
"No reviewed summary yet" state and links to the reviewed claims.

Antigravity CLI generated two 1536 x 1024 PNG variants for each school. The
selected Harvard v1 and Manchester v2 assets are delivered as optimized JPEGs
in `apps/web/public/assets/policy-scenes/`. Original candidates remain local
to the authoring workspace; only the selected, optimized assets ship.

Review these two scenes and their desktop/mobile behavior before choosing
scenes for any of the other eight pilot universities. This visual pilot does
not create or change policy claims, snapshots, source evidence, or public API
contracts.
