# UAPT 7 visual assets

## Provenance

`apps/web/public/assets/intent-path-texture.png` was generated with the
built-in Image 2 tool for this worktree. The final project copy is a 720×720
PNG. It is an auxiliary path texture only; it contains no words, policy facts,
logos, seals, university marks, or per-university imagery.

Prompt summary:

> Small no-text wayfinding texture for a restrained GitHub-style public
> university policy tracker: a single dark-blue path line with four simple
> square waypoints on a flat warm off-white field, flat two-color editorial
> screenprint, generous empty space, no gradients, text, logos, seals, UI, or
> factual content.

The generated output was visually inspected before and after copying into the
repo. It showed a clean diagonal path and four waypoints with no visible text
or institutional marks. The site uses it at low opacity behind the home-page
intent flow; the flow labels, icons, links, and all factual text remain
deterministic HTML/SVG or programmatic OG output.
