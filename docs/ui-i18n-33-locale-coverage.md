# Interface text coverage for the 33 reading locales

Base: `origin/main` `eea1eb21`. Scope: home, function pages, the framework of
non-V6 university pages, and `/changes` pages. Policy quotations, claim text,
change-record bodies, university names, source titles and tool names are data
and are out of scope.

## Where the strings live

- `apps/web/messages/public-ui/en.json` lists source strings; each
  `public-ui/<locale>.json` maps them for all 32 non-English locales
  (`pnpm validate:i18n` enforces identical keys, placeholders, protected terms
  and numbers). This change adds 1,454 keys.
- Values came, in order, from: the live reviewed reading package as rendered on
  eduaipolicy.org (aligned en/locale DOM, majority vote, validator-checked);
  ICU `Intl.DisplayNames` for country labels (positional alignment misreads
  locale-sorted `<select>` lists); the existing 7-locale dictionaries and copy
  modules for zh/fr/pl/es/nl/ms; and new translations for strings that were
  English on live too.
- 227 live strings translated the brand "University AI Policy Tracker" and 56
  translated "GenAI"; the validator forbids that, so those were re-translated
  with the brand kept.
- Source additions override the runtime package for the same key, so after R1
  these 1,454 strings come from the build, not the package.

## Code paths fixed

- Locale layout, home, trust pages (contact/support/privacy/terms/mcp),
  universities, search and ranking location labels now read
  `getPublicReadingUiText` (package + source additions) instead of the package
  only.
- `/changes/[releaseId]` renders the release overview inline so the localized
  wrapper translates it; correction notices keep only the summary preserved.
- Topic chips on `/universities`, the `/changes` country filter, the default
  `ApiEndpointRow` status, privacy section headings, MCP links and example
  questions, and the route loading message use the UI text map.
- Non-V6 university framework labels use the 7-locale reference dictionary for
  legacy locales, not only in reference preview.
- Language switcher: non-V6 university pages offer English and Simplified
  Chinese only. hreflang and sitemap for those schools were already English-only
  and are unchanged.
