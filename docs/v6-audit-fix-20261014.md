# Ten-school V6 scoped correction

This revision repairs the confirmed findings in the 2026-10-13 merged audit. It
aligns the ten reviewed university records, V6 projection, canonical public APIs,
tools, search mapping and MCP. The global dataset release remains
`public-release-20260924-002`; `universityRevisionId` identifies this scoped change.

The correction includes NUS detector evidence, assessment modality and marking
approval, Caltech tool/admissions versions and HSS summary, ETH declaration
exceptions, Oxford quote/citation/source status, Cambridge titles and UCL/ETH
aliases. Source-only objects, scoped tool access and unknown dates receive explicit
labels. A university tool listing does not grant assessment permission.

Seven student summaries are regenerated on their current claim fingerprints and
remain `needs_review`; historical approvals do not approve new fingerprints. ETH,
UCL and Caltech still have no published student snapshot. Six obsolete or held
claims remain in historical records, including the unverified NUS appeal clock.
Unresolved source and supplementary-object gaps remain recorded. This scoped
repair is not a new complete institutional audit or seven-language translation.

The original V6 revision and historical record JSON remain addressable. The new
changes index, per-school history, scoped diff, recent changes and RSS belong to
the same release. Private source paths are excluded from the new public package.

Source normalization verifies raw and extracted-text files separately. The
original-file hash identifies the source snapshot; extracted-text hashes and
positions identify quote locations. Evidence mapped to the wrong source must
fail preparation and receive an explicit correction rather than weakening MCP
validation. The frozen source-binding receipt retains original bindings.

Release class B: only the shared `@uapt/tulsa-zone` is built on OCI from the pushed
SHA. MCP uses an isolated pinned catalog and service. Main-site code and previous
zone/assets remain available for rollback. Candidate synchronization contract
2.0.0 is checked before exact-route selection; public readback and bounded
changed-URL notification have separate completion evidence. Build success alone
is not publication acceptance.
