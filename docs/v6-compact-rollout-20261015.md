# Shared compact V6 rollout

Promotes the accepted Imperial composition to the thirteen actually published V6 schools. Peking University remains on V5. One shared composition and style sheet replace school-specific UI branches. Original policy records, tool objects, quotations, source metadata, dates, historical reviews and snapshot holds remain unchanged. The new school-bound action/readthrough projections are presentation data, not a policy release or a complete institutional audit.

Scope: four compact task questions; explicit desktop equal-height topics; natural phone heights; Chinese reading guides with full English scope; submission shortcut; individual action evidence; neutral prose with semantic titles and borders; 12px labels; shareable, full-screen mobile concern reader; no scenario artwork or duplicate checkbox checklist; expandable FAQ. Each school's procedures keep their own scope and gaps. Original assets and MIT published supplements remain available in the repository and evidence layer.

Release method: bounded shared-zone OCI build B, exact fourteen-policy-school compatibility readback, candidate and public synchronization 2.0 gates, unchanged V5/main/MCP controls, and retained rollback. Actual acceptance will be appended after verification.
