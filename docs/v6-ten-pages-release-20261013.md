# V6 ten-page bounded release

This release uses the OCI small-release B path: only `@uapt/tulsa-zone` is built. Its exact ten university identities are recorded in `data/public-v6-pages/current.json`. Seven existing locale routes use the same reviewed V6 composition and immutable public page projection; original quotations, scoped tools, unknown conditions and held decisions stay explicit. This is a page-supplement publication, not a new university policy enactment or canonical dataset promotion. The canonical APIs, tools, snapshots and MCP continue to use their published dataset baseline; the supplement has its own JSON and changes endpoint. No private inventory or raw archive is shipped.

The release routes update the ten university pages, their changes/history pages, the changes index and recent-change RSS. `v6-pages-20261013` records the separate page-supplement revision and evidence fingerprints. Existing historical changes remain available. Only tested paths are selected in nginx, with independent static assets and full document navigation across zones. The main service on 3100 and earlier services remain available for rollback; no mixed Next build output is copied into them.

Source SHA, OCI BUILD_ID, the content SHA, actual route matrix, candidate/public readbacks, browser acceptance and synchronization contract 2.0.0 are recorded separately in the private release evidence. Public readback is required after the same accepted artifact is selected. Policy scope gaps and five-language English fallbacks do not become complete institutional audits or reviewed translations by deployment.
